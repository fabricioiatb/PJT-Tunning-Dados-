# Serviço de Clientes

Responsável pelo CRUD de clientes, veículos e planos de mensalista.

**Banco:** PostgreSQL (RDB)

**Endpoints previstos:**
- CRUD de clientes
- CRUD de veículos
- CRUD de planos (mensalista)
- Endpoint interno para o Serviço de Sessões consultar se um veículo tem plano ativo em uma garagem
