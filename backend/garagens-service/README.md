# Serviço de Garagens

Responsável pelo CRUD das unidades da rede: endereço, vagas por tipo e tabela de tarifas.

**Banco:** MongoDB (DB1 — document store)

**Endpoints previstos:**
- CRUD de garagens (com vagas e tarifas embutidas no documento)
- Endpoint interno para o Serviço de Sessões consultar a tarifa de uma garagem
